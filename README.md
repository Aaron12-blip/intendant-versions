# Intendant pour Windows

Intendant organise et surveille ton PC : il repère les doublons et les fichiers volumineux, range tes dossiers en pouvant tout annuler, et montre en direct l'état de ta machine.

Ce dépôt ne contient que les installateurs pour Windows.

## Installer

Télécharge `Intendant-Installation-<version>.exe` depuis la [dernière version](https://github.com/Aaron12-blip/intendant-versions/releases/latest), puis lance-le. Il installe Intendant pour ton seul compte, sans droits d'administrateur, et l'ajoute au menu Démarrer. Il faut un Windows 64 bits ; Intendant a été testé sous Windows 11.

L'installateur n'est pas signé : Windows peut afficher « Windows a protégé votre ordinateur ». Clique alors sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Mises à jour

À partir de la version 1.1.0, Intendant vérifie lui-même s'il existe une nouvelle version. Quand c'est le cas, la Vue d'ensemble l'annonce, et un clic sur **Mettre à jour** suffit : Intendant télécharge la nouvelle version, vérifie qu'elle est bien celle publiée ici, l'installe, puis se rouvre. Tes réglages, ton historique et le scan planifié sont conservés.

Cette vérification se coupe dans **Réglages**, section **Application**. Le bouton **Vérifier** de cette section permet aussi de vérifier à tout moment.

## Désinstaller

Dans **Paramètres** > **Applications**, choisis Intendant, puis **Désinstaller**. Tes réglages et ton historique sont conservés.
